# Hub tilemap Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the procedural hub (noise tiles and shape trees) with a 16×16 tile map that reads like a top-down 16-bit RPG, using Phaser's built-in tilemap. Keep movement, the three boss gates, the React HUD, and the entry panel.

**Architecture:** [Tiled](https://www.mapeditor.org/) JSON in `public/game/hub.json` is the map. Phaser 4.2.1, already installed, loads it with `this.load.tilemapTiledJSON`, `this.make.tilemap`, and `createLayer`. Arcade physics, already enabled, collides the player with a hidden collision layer. Gate and spawn positions live on a Tiled object layer, not in TypeScript. React still owns the entry panel through `GameBridge`.

**Tech Stack:** Next.js 16 App Router, React 19, Tailwind 4, Phaser 4.2.1, a CC0 16×16 tileset. No new runtime dependency.

**Deviations recorded during implementation (2026-09-26):**

- Kenney Tiny Town has no water tile, so the pond is a fenced cobblestone plaza. It still blocks movement.
- The map has a fourth tile layer, `props`, between `ground` and the player. Trees, sprouts and mushrooms are transparent tiles; drawing them on `ground` in place of grass showed the canvas background. `overhead` (fences, sign) stays above the player.
- `hub.json` was generated by a throwaway script kept outside the repo, then checked with the Task 3 validation snippet. The JSON is the artifact; there is no generator in the repo.

### Task 3: Author the Tiled map

**Files:**
- Create: `apps/web/public/game/hub.json`

**Interfaces:**
- Consumes: gids recorded in `TILESET-LICENSE.txt`. Tileset name must be exactly `hub`. Image key used later is `tiles`.
- Produces: a map Phaser can load. Layers: `ground`, `overhead`, `collision`, object group `markers`. Map size 40×30, tile size 16. Object names and properties below are what Task 4 reads.

Marker objects, in Tiled pixel coordinates (origin top-left of the map):

| Object `name` | `x` | `y` | Property `bossId` |
| --- | --- | --- | --- |
| `spawn` | 320 | 400 | none |
| `gate` | 96 | 96 | `cat` |
| `gate` | 544 | 96 | `macro-whale` |
| `gate` | 320 | 48 | `locked` |

Each `gate` object is a rectangle 48 wide and 32 tall. `spawn` is a point. `bossId` is a string property.

Walkable shape: a vertical path from the spawn up to a horizontal path that reaches the cat gate (left), the whale gate (right), and the locked gate (up). Water in the bottom-left, about 4×3 tiles, and that water is on the collision layer. Scatter blocking tree tiles beside the paths, not on them. Fill everything else with grass. `overhead` may be all zeros in this slice. `collision` uses the tree gid (and the water gid) on blocked cells and 0 on walkable cells.

```ts
  private buildGates(map: Phaser.Tilemaps.Tilemap) {
    const group = this.physics.add.staticGroup();
    const objects = map.getObjectLayer("markers")?.objects ?? [];
    for (const object of objects) {
      if (object.name !== "gate") continue;
      const bossId = object.properties?.find((p) => p.name === "bossId")?.value;
      if (bossId !== "cat" && bossId !== "macro-whale" && bossId !== "locked") {
        throw new Error(`Gate is missing bossId at ${object.x},${object.y}`);
      }
      const boss = findBoss(bossId);
      const x = object.x + object.width / 2;
      const y = object.y + object.height;
      const color = GATE_COLORS[boss.id];

      const glow = this.add.circle(x, y - 20, 18, color, boss.locked ? 0.25 : 0.45).setDepth(y);
      if (boss.locked) {
        this.add.rectangle(x, y - 16, 10, 8, 0x8a8fa3).setDepth(y + 1);
      } else {
        this.add.image(x, y, `portrait-${boss.id}`).setOrigin(0.5, 1).setDepth(y + 1);
      }

      const label = this.add
        .text(x, y + 4, boss.locked ? "LOCKED" : boss.name.toUpperCase(), {
          fontFamily: "var(--font-dm-mono), monospace",
          fontSize: "8px",
          color: boss.locked ? "#9aa0b4" : "#f3f3f8",
        })
        .setOrigin(0.5, 0)
        .setDepth(LABEL_DEPTH + 1)
        .setResolution(2);
      this.add
        .rectangle(x, label.y + label.height / 2, label.width + 6, label.height + 3, 0x0b0e18, 0.75)
        .setDepth(LABEL_DEPTH);

      const body = this.add.rectangle(x, y - 8, object.width, 12).setVisible(false);
      group.add(body);

      this.gates.push({
        boss,
        zone: new Phaser.Geom.Rectangle(object.x - 8, object.y + object.height, object.width + 16, 28),
        glow,
      });
    }
    return group;
  }
```
